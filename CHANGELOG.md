# Changelog

All notable changes to this package will be documented in this file.

This project follows semantic versioning for published releases.

## [0.1.0] - Initial Release

- Added the initial Trakt TypeScript wrapper with OAuth helpers.
- Added typed endpoint groups for auth, search, movies, shows, seasons,
  episodes, calendars, users, sync, scrobble, check-in, and lists.
- Added pagination helpers for Trakt response headers.
- Added Bun-compatible build, test, and typecheck scripts.
